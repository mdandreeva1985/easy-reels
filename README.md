# Заголовки для Reels

Веб-приложение: накладывает заголовки (белая плашка, чёрный текст) на видео и собирает пачку рилсов прямо на устройстве (iPhone, Android, компьютер). Видео никуда не отправляются.

Использует библиотеку [Mediabunny](https://github.com/Vanilagy/mediabunny) (лицензия MPL-2.0, см. `vendor/`).
